# ESP32-S3 遥控器桥接 · 使用手册（v2.0.0）

本手册覆盖 **PC 客户端每一页**、**手机 APP 每一页**，以及配对、刷写与常见问题。
如果你是第一次使用，先看「快速开始」，其余按页查阅。

---

## 一、它是什么

一块 ESP32-S3 开发板把「遥控器 / 手机」变成电脑的 **USB 键盘 + 鼠标 + 麦克风**：

- **遥控器**：Chromecast 蓝牙遥控器，通过 BLE 连板子；按键可映射成任意键盘/鼠标/媒体动作。
- **手机**：安装 APK 后通过 BLE 连板子，当触控板、陀螺仪空鼠、文字输入、语音麦克风、自定义快捷键面板。
- **PC 客户端**：负责配置映射、配对、语音识别（走 Windows 输入法）、诊断日志、固件刷写。

数据流：手机/遥控器 → BLE → 板子 → USB HID/UAC → 电脑。

---

## 二、快速开始

1. **给板子刷固件**：首次用「烧录」（全量，会清空配置）；以后升级选 Release 里唯一的 `remote_bridge-2.0.0.bin` 点「仅应用」（保留配置）。详见第七章。
2. **打开 PC 客户端**，插上板子（USB 数据口），确认「设备状态 → 开发板」显示端口、固件版本。
3. **配对遥控器**：「蓝牙配对」→「进入配对模式」→ 按一下遥控器（长按 Home 进入配对）。
4. **装手机 APP**：`Fremote-2.0.0.apk` → 打开 → 若首次会进「设置」页 →「扫描」→ 点 `remote-bridge` 连接。
5. 开始使用：遥控器直接按；手机在触控板页操作；需要语音时长按麦克风。
6. **中文输入**：由 PC 端输入法出字，手机/板子不负责识别。使用前把 PC 输入法切到中文。

# 三、PC 客户端

左侧三个页签：**设备 / 按键 / 语音**。

## 3.1 设备页

### 设备状态
- **开发板**：显示串口端口与连接状态；右键/刷新可重新识别。
- **固件版本**：板子当前运行的版本，「刷新」重新读取。

### 刷写固件
- 端口下拉（默认 COM6，板载 UART，最稳）。
- **选固件**：不选则使用安装包内自带的固件；「仅应用」只写应用分区；「烧录」会写 bootloader + 分区表 + 应用（全新刷写，**会清掉 NVS 里的映射/配对**，会二次确认）。
- 状态显示「就绪 / 烧写中 x%」。

### 蓝牙配对
- **配对模式**：显示「已关闭 / 剩余 N 秒」；点「进入配对模式」后板子专心扫描，已连的遥控器会暂时断开，窗口内扫到的新遥控器自动配上。
- **遥控器**：已连接 / 已配对数量（0/2 表示最多两台）。
- **附近的遥控器**：「扫描」列出周围醒着的遥控器，点「连接」配对。
- **已配对列表**：每台显示名称、身份地址、状态（已连接 / 在睡觉）；
  - **重命名**：给遥控器起自己的名字（同型号多台时区分）；
  - **删除**：解绑并删除该遥控器的映射。
- **手机行**（Xiaomi … / 手机 App · MAC）：显示真实机型与蓝牙地址；
  - **重命名**：给这台手机起名；
  - **删除 / 断开**：断开并让板子**拒绝这台手机自动重连**，直到重新进入配对窗口。

### 通用设置
- **随 Windows 启动**：登录后自动在后台运行。
- **关闭窗口时隐藏到任务栏**：关掉窗口只缩到托盘，右下角图标可再打开；关闭则退出程序。

### 按键自检
点「发一次」让板子造一个假按键事件：板端灯会闪一下，下方日志会多一行——用来确认板子与客户端链路正常。

### 诊断日志
实时显示人话日志（时间 / 哪台设备 / 按了什么 / 变成什么）。「导出日志」保存到「下载」文件夹，「打开日志位置」直接定位。

## 3.2 按键页

顶部是**遥控器切换条**：手机（临时遥控器）/ 各台已配对遥控器。不同布局的键位互不干扰。

### 遥控器布局（谷歌遥控器）
- 中间是实物图，左右是 15 个按键卡片；点按键或卡片都会选中同一项。
- 每张卡片三列：**单击 / 双击 / 长按**。
- 点卡片打开动作编辑器：
  - 下拉里是预设动作（键盘语义、系统、鼠标、打开应用…）；
  - 组合键直接输入框里写，如 `ctrl+shift+p`；也可点「录入」按键录制；
  - 备注可自定义显示名；
  - 「完成」自动保存并写入板子（组合键由板子执行，**不依赖 PC**）。
- 底部工具栏：
  - **检测真实按键**：按一下遥控器上的键，自动选中对应行；
  - **启动应用…**：管理「打开应用」用的程序清单；
  - **恢复型号默认 / 存为型号默认**；
  - **导出配置 / 导入配置**（JSON）。

### 手机布局（自定义快捷键）
- 中间是「快捷键」画布；每个自定义键是画布上的一个方块，背景为 3 列网格。
- **拖动方块**：吸附到最近的格点；目标格已有键则交换位置。
- 左右卡片与原遥控器一致，连线指向画布上的按钮；点按钮或卡片都选中同一项。
- 卡片左侧名字**单击改名**、**右键删除**（会确认，映射一并清除）。
- 底部「＋ 添加快捷键」在工具栏左侧；最多 64 个，多了会滚动。
- 每个键可配：**组合键**（板子执行，关掉 PC 也能用）或 **打开应用**（需要 PC 在线）。

## 3.3 语音页

- **音频前置**：开发板麦克风（USB UAC）作为 Windows 录音设备。
- **语音通道**：ATVV / HID 直传等选择与状态。
- **选择输入法**：电脑上用哪个输入法出字（微信、搜狗、微软等，按已安装列出）。
- **按键模式 / 语音按键**：按住说话的触发方式与热键（可录制）。
- **最近触发**：最近一次语音识别结果，便于确认链路。
- **遥控器**：若有带麦克风的遥控器，这里显示其语音键状态。

# 四、手机 APP

## 4.1 设置页

从触控板右上「⋮（设置）」进入；首次安装没有保存地址时会直接进入本页。

- **开发板（remote-bridge）**：扫描 → 列表点「连接」；已保存地址时会自动回连。
- **触控板灵敏度**：1.0 ~ 10.0（默认 4.0）。
- **空鼠（陀螺仪）灵敏度**：0.1 ~ 5.0（默认 0.6）。
- **输入停顿后自动发送**：0.3 ~ 3.0 秒（默认 0.6）。
- **操作手**：左手 / 右手（滚轮条放哪边）。
- **显示模式**：显示系统栏 / 全屏沉浸。
- **主题**：夜间 / 日间（所有页面统一）。
- **语言 / Language**：中文 / English（所有页面统一）。
- **确定**：保存并留在本页（不会自动跳走）；「‹ 返回」回触控板。

## 4.2 触控板页

### 顶部
- **输入条**：直接打字，停一下就发送到电脑光标处（时间见设置）；右侧「退格」「发送（↑）」。
- **四个快捷键**：ESC / 音量− / 音量+ / **打开网站**。
  - 打开网站：单击打开一个网页（默认 B 站），**长按可修改网址**。

### 触控板 / 陀螺仪（底部左侧切换）
- 点一次在「触控板 ↔ 陀螺仪」之间切换，图标和文字跟着变。
- **触控板**：单指移动；轻点左键；双指滚动/捏合缩放（随系统）；右侧滚轮条可拖动或长按箭头连续滚。
- **陀螺仪**：左右两块分别为左键、右键；中间滚轮条同触控板；灵敏度在设置里调。

### 自定义快捷键（底部右侧）
- 点「快捷键」进入第三种模式：页面中间变成你自定义的按键面板，**上方输入条与四个快捷键仍然可用**。
- 按钮按 3 列排列，可上下滑动；按钮名字就是你在 PC 上起的名字。
- 按钮动作在 PC 端「按键 → 手机布局」配置（组合键或打开应用）。
- 再点「快捷键」或「触摸板」即切回。

### 麦克风（底部中间）
- 按住说话，松手立即结束并收起浮层；识别由 PC 输入法完成，出字到电脑光标处。
- 轻点麦克风可唤起键盘（输入法）打字。

## 4.3 键盘页

触控板页右上「键盘」图标进入：标准键盘布局，可锁定 Ctrl/Shift/Alt/Win，打出的字直接发到电脑；「发送/回车」提交；「返回」回触控板。

## 4.4 语音浮层

- 长按麦克风出现：显示「正在聆听」与波形；
- 松手即退出，不再停在「识别中」；
- 识别结果显示在电脑上（输入法），手机端不显示最终文本。

# 五、配对、删除与多设备

- **删除配对在 PC 端**：「设备」页对应行右侧「删除」（手机、遥控器同页）。
- **手机没有删除入口**（防止手机自己解除限制），只能在设置页扫描/连接。
- **PC 删除手机后**：板子会拒绝这台手机自动重连；手机提示「已被电脑端移除」并每 10 秒再试。
  想恢复：PC「进入配对模式」→ 手机在 10 秒内自动连回（或到设置页手动点连接）。
- **首次安装**：打开 APP 无保存地址 → 设置页扫描 → 点 `remote-bridge`。
- **自动连接只针对保存过的 MAC**：附近有别人的同款板子不会连错。
- **一台板子同时可连**：最多 2 台遥控器 + 1 台手机；互不影响。

# 六、灯语

| 状态 | 表现 |
|---|---|
| 完全空闲（没有任何链路） | 蓝色缓慢呼吸（在找设备） |
| 遥控器或手机在线 | 熄灭（待机不亮） |
| 有按键 / 手机操作 | 青色一闪即灭（150ms） |
| 语音收音中 | 粉色（松手约 0.8 秒后熄灭） |
| 配对成功 | 绿色快闪 1.5 秒 |
| 配对窗口开启 | 蓝色快闪 |

# 七、刷写与回退

- **日常升级**：设备页「选固件」→ 选 Release 里唯一的 `remote_bridge-2.0.0.bin` → 点「仅应用」（写 `0x10000`）。配对、映射、快捷键全部保留。
- **首次刷写 / 救砖**：不用单独下载 bootloader 和分区表，直接点「烧录」，客户端会用绿色包内 `_internal/firmware/` 的三件套按 `0x0` / `0x8000` / `0x10000` 写入。**这会清空板子上的映射与配对**，建议先「导出配置」。
- GitHub Release 只提供应用固件一个 bin；旧 WiFi 回退版已停用，不再发布。

# 八、常见问题

**手机连不上板子 / 一直「连接中」**
1. 先关一次手机蓝牙再打开（安卓蓝牙栈偶尔僵死）；
2. 确认板子灯不是蓝呼吸（说明有链路）；板子重启后等 5 秒；
3. 到设置页重新扫描连接。

**中文打不出来**
手机/板子只发按键与麦克风音频；中文由 PC 输入法出字。请把 PC 输入法切到中文，并保持 PC 客户端运行。

**设置改了不生效**
「确定」保存后再回触控板；灵敏度/操作手/停顿是电脑端即时读取的，不依赖重启。

**删除手机后又自己连回来**
正常版本会拒绝；如果你用的是旧固件/旧 APK，请升级到 2.0.0。

**两台遥控器只认一台**
遥控器空闲不广播；用的时候按一下它就会连上。已配对的两台可同时在线。

**客户端显示「固件 1.6.x」**
板子还没刷 2.0.0：设备页先「烧录」。

**手机 App 界面是英文**
设置页 →「语言 / Language」→ 中文。
